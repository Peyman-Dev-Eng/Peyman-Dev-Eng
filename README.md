## About

I'm a **C++ developer** focused on understanding and building software systems from their foundations. I enjoy designing architectures, implementing core components, and solving the engineering challenges that emerge when theory meets real code.

My work and learning are centered around **game-engine development, 2D graphics, and modern C++**. I place particular value on sound software design, understanding low-level behavior, and building a solid grasp of the algorithms and data structures behind the systems I use.

I believe the best way to understand a system is to study its foundations, experiment with its design, and build meaningful parts of it yourself.

## Featured Project

### 🌊 [Lucid Drift](https://github.com/Peyman-Dev-Eng/Lucid_Drift)

**An experimental 2D game engine and editor built with modern C++ and OpenGL.**

Lucid Drift is my primary ongoing project. Its goal is to explore the architecture behind a 2D engine while bringing rendering, editing, and game-project workflows together in one native application.

**Current areas of development include:**

- **Rendering:** a custom OpenGL rendering path using GLSL shaders.
- **2D Geometry:** circles, lines, polygons, polygon triangulation, and outline-joining algorithms.
- **Editor:** an interface built with Dear ImGui, including project browsing and embedded source editing.
- **Game Project Workflow:** CMake-based project compilation and an engine-facing API for loading game modules.
- **Engine Systems:** camera, input, transforms, scene-related functionality, and project settings.
