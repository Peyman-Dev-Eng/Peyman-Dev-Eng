## 🔥 Featured Projects

### 🎮 [NexusEngine](https://github.com/Peyman-Dev-Eng/NexusEngine)
**A lightweight 2D game engine written in modern C++ (C++23/C++26) on top of SFML**

- Custom window management system
- Advanced collision detection (Spatial Hashing + Separating Axis Theorem)
- Low-level input system (direct from `/dev/input`)
- Custom Shape Actors (Circle, Rectangle, Polygon)
- Homegrown data structures
- Fixed FPS game loop

> ⚠️ Currently runs **only on Linux**.
